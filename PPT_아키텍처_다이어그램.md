## 슬라이드: 상세 기술 스택

### 외부시스템
- **다나와 웹사이트**
  - 크롤링 대상
  - 9개 카테고리 (CPU, 쿨러, 메인보드, RAM, VGA, SSD, HDD, 파워, 케이스)

### Crawler
- **Python 3.11**
- **Playwright** - 브라우저 자동화
- **BeautifulSoup4** - HTML 파싱
- **SQLAlchemy** - ORM
- **PyMySQL** - DB 연결

### DB
- **MySQL 8.0**
- UTF-8 인코딩
- Docker 볼륨으로 데이터 영구 저장
- Health Check 포함

### Backend
- **Spring Boot 3.2**
- **Java 17**
- **Maven** - 빌드 도구
- **JPA/Hibernate** - ORM
- **REST API** - JSON 통신

### Frontend
- **React 18**
- **JSX/TSX** - 컴포넌트 작성
- **CSS** - 스타일링
- **Vite** (개발 서버)
- 핫 리로드 지원

### Summarizer
- **Python 3.11**
- **Google Generative AI** - 리뷰 요약
- 퀘이사존 리뷰 수집 및 분석

### AI (Google Gemini)
- **Gemini 1.5 Flash**
- 자연어 처리 및 생성
- PC 견적 추천
- 호환성 검사
- 챗봇 대화형 상담

## 슬라이드: Docker 환경 구성

### Docker Compose 서비스
```
┌─────────────────────────────────────────────────────────┐
│              Docker Compose Services                    │
└─────────────────────────────────────────────────────────┘

┌──────────┐    ┌──────────┐    ┌──────────┐
│    DB    │    │ Backend  │    │ Frontend │
│  MySQL   │    │SpringBoot│    │  React   │
│  :3307   │    │  :8080   │    │  :3000   │
└──────────┘    └──────────┘    └──────────┘

┌──────────┐    ┌──────────┐
│ Crawler  │    │Summarizer│
│ (수동)   │    │  (수동)  │
└──────────┘    └──────────┘

네트워크: danawa-net (bridge)
볼륨: db_data (MySQL 데이터 영구 저장)
```

### 실행 명령어
```bash
# 전체 서비스 실행
docker-compose up -d db backend frontend

# 크롤러 실행
docker-compose run --rm crawler python crawler.py

# 요약 서비스 실행
docker-compose run --rm summarizer python summarize_reviews.py
```

### 1. 데이터 수집 (Crawler)

- 제조사 필터링
- 키워드 검색
- 실시간 필터링

- 사용자 예산/용도 기반 추천
- 부품 호환성 자동 검사
- 자연어 설명 생성
- 단계별 질문 인터페이스

### 4. AI 챗봇 (AI)
- 대화형 PC 견적 상담
- 부품 추천 및 비교
- 호환성 질의응답
- 컨텍스트 기반 대화

### 5. 리뷰 요약 (Summarizer + AI)
- 퀘이사존 리뷰 수집
- AI 기반 리뷰 요약
- 핵심 정보 추출
- DB 저장 및 조회

## 슬라이드: 개발 환경 특징

### 도커 기반 개발 환경
✅ **환경 일관성**
- 모든 개발자가 동일한 환경
- OS 독립적 실행

✅ **빠른 설정**
- 한 번의 명령어로 전체 환경 구축
- 신규 개발자 온보딩 시간 단축

✅ **의존성 격리**
- 로컬 환경 오염 방지
- 버전 충돌 방지

✅ **배포 간소화**
- 개발 환경 = 프로덕션 환경
- 컨테이너 기반 배포 가능

### 핫 리로드 지원
- Frontend: 코드 수정 시 자동 새로고침
- Backend: 재빌드 후 자동 재시작
- Crawler: 볼륨 마운트로 즉시 반영

- Docker Compose 기반
- 5개 서비스 (DB, Backend, Frontend, Crawler, Summarizer)
- 핫 리로드 지원
- 환경 일관성 보장

### 주요 기능
- 자동 데이터 수집
- 실시간 부품 검색
- AI 견적 추천
- AI 챗봇 상담
- 리뷰 요약
