# 🤖 AI PC 추천 시스템 (AI Build)

## 📋 프로젝트 개요

**AI PC 추천 시스템**은 사용자의 요구사항과 예산에 맞춰 최적의 PC 부품 조합을 추천하는 인터랙티브 웹 애플리케이션입니다. AI 가상 어시스턴트 "다오나"가 사용자와 대화하며 PC 구성을 안내합니다.

### 🎯 주요 목표

- 사용자 친화적인 대화형 인터페이스로 PC 부품 선택 과정 단순화
- AI 기반 맞춤형 부품 추천 및 호환성 검증
- 예산 관리 및 부품 비율 최적화
- 실시간 견적 계산 및 시각화

---

## ✨ 현재 완료된 기능

### 🎨 Phase 1: 인트로 & 채팅 시스템
- ✅ **인트로 화면**: 다오나의 환영 메시지와 페이드아웃 애니메이션
- ✅ **4단계 대화형 채팅**: 
  - 사용자 숙련도 확인
  - 스펙 인지도 파악
  - 모니터 보유 여부
  - 견적 목적 확인
- ✅ **AI/사용자 아바타**: 시각적으로 구분된 대화 버블
- ✅ **자동 스크롤**: 새 메시지 표시 시 자동 스크롤

### 🛠️ Phase 2: SidebarStack1 - 상세 설정
- ✅ **예산 설정**:
  - Min/Max 텍스트 입력
  - 범위 내 슬라이더
  - 예산 유연성 조절 (0-20%)
  
- ✅ **사용 목적 선택** (다중 선택):
  - 게임, 영상편집, 코딩/AI, 디자인, 사무

- ✅ **부품 비율 관리**:
  - 9개 부품 카테고리별 비율 슬라이더
  - 잠금 기능 (🔒/🔓 토글)
  - 총합 100% 자동 유지
  - AI 자동 비율 설정 (사용 목적 기반)

- ✅ **성능 우선도**:
  - 작업 강도 선택
  - 멀티태스킹 수준
  - 그래픽 목표

- ✅ **케이스 및 환경**:
  - 케이스 크기 (풀타워/미들/미니/SFF)
  - 패널 타입 (강화유리/밀폐형/메쉬/정면유리)

- ✅ **전력 효율 및 소음**:
  - 전력 절약 모드
  - 소음 기준 설정

- ✅ **디자인 및 외관**:
  - 컬러 테마 선택 (최대 3개)
  - RGB 조명 옵션
  - 소재 선택

- ✅ **업그레이드 및 내구성**:
  - 업그레이드 계획
  - AS 중요도
  - 사용 예상 기간

- ✅ **설정 요약 카드**: 주요 설정 한눈에 보기
- ✅ **액션 버튼**: 초기화, 설정 저장, 설정 불러오기

### 📦 Phase 3: SidebarStack2 & Stack3 - 부품 선택
**SidebarStack2 (부품 카테고리 선택):**
- ✅ **진행도 트래커**:
  - 그래디언트 배경 + 진행도 바
  - 카테고리별 상태 배지 (✓/⏳/빈칸)
- ✅ **카테고리 카드**:
  - 각 부품별 아이콘 (🖥️🎮🔲💾💿🗄️⚡📦❄️🖥️)
  - 상태별 그래디언트 배경
  - 호버 효과 (그림자 + 이동)
  - 확정된 부품 잠금 표시
- ✅ **모델 선택 UI**:
  - 세로 확장 애니메이션
  - 호버 시 슬라이드 효과
- ✅ **AI 자동 구성 버튼**: 한번에 전체 부품 추천

**SidebarStack3 (제품 세부 선택):**
- ✅ **검색 기능**: 제품명/브랜드 실시간 검색
- ✅ **정렬 옵션**:
  - 추천순 (AI 매칭)
  - 최저가순
  - 리뷰 많은 순
  - 브랜드순
- ✅ **브랜드 필터**: 가로 스크롤 칩 UI
- ✅ **제품 카드**:
  - 제품 이미지 플레이스홀더
  - 재고 상태 배지
  - 배송 정보 (무료/유료)
  - 리뷰 수
  - AI 매칭 점수 (시각적 바)
  - 가격 정보
  - Quasarzone 리뷰 태그
- ✅ **빈 결과 처리**: 검색 결과 없을 때 안내 메시지

### 📊 Phase 4: SidebarStack4 - 최종 견적
- ✅ **견적 테이블**:
  - 3열 그리드 레이아웃 (카테고리/제품정보/가격)
  - 카테고리별 컬러 배지
  - 제품명 + 스펙 표시
  - 홀짝 행 구분
- ✅ **예산 요약 카드**:
  - 그래디언트 보라색 배경
  - 총 견적 금액
  - 잔액 표시 (+/- 표시)
  - 예산 사용률 진행 바
- ✅ **다오나 메시지**: 견적 완성 축하 메시지
- ✅ **액션 버튼**:
  - 🔄 초기화
  - 💾 견적서 저장
  - 📝 PDF 출력
  - 🤖 AI 재검토 (호환성/전력/예산 체크)

### 🎨 Phase 4: 디자인 시스템 개선
- ✅ **Light Mode 테마**:
  - 배경: `#f8fafc`
  - 액센트: `#2563eb`, `#6366f1`, `#8b5cf6`
  - 텍스트: `#1e293b`
- ✅ **그래디언트 사용**: 주요 UI 요소에 모던한 그래디언트 적용
- ✅ **아이콘 추가**: 모든 섹션에 이모지 아이콘 추가
- ✅ **호버 효과**: 부드러운 transition과 shadow 효과
- ✅ **애니메이션**: pulse, slideUp, slide-in 애니메이션
- ✅ **사용자 메시지 버블**: `#6366f1` 그래디언트로 변경

## 🎯 추천 다음 개발 단계

### 우선순위 1: 백엔드 연동
1. **API Endpoints 연결**:
   - `GET /api/parts` - 부품 카테고리 목록
   - `GET /api/parts/{category}` - 카테고리별 모델 목록
   - `GET /api/products?model={model}` - 모델별 제품 목록
   - `POST /api/estimates` - 견적서 저장
   - `GET /api/estimates/{id}` - 저장된 견적서 불러오기

2. **데이터 모델 정의**:
   ```javascript
   // 부품 카테고리
   {
     id: "cpu",
     name: "CPU",
     models: ["AMD Ryzen 7 7800X3D", "Intel i7-14700K"]
   }
   
   // 제품
   {
     id: 1,
     name: "AMD Ryzen 7 7800X3D",
     category: "cpu",
     model: "AMD Ryzen 7 7800X3D",
     price: 489000,
     brand: "AMD",
     specs: "8코어 16스레드",
     stock: "재고풍부",
     shipping: "무료배송",
     reviewCount: 342,
     aiScore: 95
   }
   ```

### 우선순위 2: AI 알고리즘 구현
- **AI 자동 비율 고도화**: 사용자 답변 기반 머신러닝 모델
- **호환성 검증 엔진**: CPU-메인보드, PSU-전력 등
- **가격 최적화 알고리즘**: 예산 내 최고 성능

### 우선순위 3: 사용자 경험 개선
- **저장/불러오기**: 로컬스토리지 + 백엔드 연동
- **PDF 출력**: 실제 PDF 생성 기능
- **SNS 공유**: 견적서 이미지 생성 및 공유
